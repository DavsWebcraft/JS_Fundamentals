# JavaScript Assessment: My Personal Profile

The HTML and CSS are already completed. **Your task is to write JavaScript in `script.js`.**

## Get the project

Clone this repository:

```bash
git clone YOUR-REPOSITORY-URL
```

Open the folder in VS Code. Open `index.html` in your browser (Live Server is recommended).

## See your JavaScript output

Open Developer Tools and select **Console**:
- Windows/Linux: `F12` or `Ctrl + Shift + J`
- Mac: `Cmd + Option + J`

## Your tasks

1. **Variables:** Use `var`, `let` and `const` to store information about yourself. Display the values, reassign a `let` variable and explain `let` vs `const`.
2. **Naming conventions:** Identify invalid variable names, correct them and write examples using camelCase.
3. **Primitive types:** Create examples of string, number, boolean, undefined and null.
4. **Non-primitive types:** Create an array of favourite foods and an object containing details about yourself. Explain one difference between arrays and objects.
5. **Mini project:** Store and display your profile details using variables, arrays and objects.
6. **Understanding check:** Answer the eight questions in comments at the bottom of `script.js`.

## Rules

- Do not edit `index.html` or `style.css`.
- Complete the tasks marked `TODO` in `script.js`.
- Use your own information and examples.
- Use `console.log()` to display your work.
- Add comments where asked.
- Be ready to explain your code.
